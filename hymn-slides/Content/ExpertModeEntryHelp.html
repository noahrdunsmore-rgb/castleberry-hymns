To add hymns, enter the expert mode instructions, then press ENTER.

Separate hymn numbers with a semi-colon ;.  Parts of a hymn can optionally follow the number using a colon : for separation.

Format ###[:vv...][;###[:vv...]]

Where ### is a hymn number, v is a verse number, C for chorus, D for coda, R for refrain, S for sanctus, and A for amen.

(Internal Viewer ONLY – does not export) To add a blank text-only slide enter W for white or B for black instead of a hymn number. Text can be added on these blank slides using a colon : then typing the message to be displayed.

Numeric Keypad

Since Expert Mode is used (in conjunction with Internal Viewer) during a song worship service where speed is key, the vast majority of hymns can be specified using only the numeric keypad.  The semi-colon is entered by pressing the slash / key, the colon is entered by pressing the minus - key, and the chorus can be specified using the plus + key.  All other non-numeric keys are must be entered using the alpha portion of the keyboard.

Expert Mode Entry allows the user to press * to jump to the currently displayed hymn part in the Displayed Hymn Tree if the Internal Viewer is visible.

Use of the Auto Add Chorus button

When Auto Add Chorus button is enabled (default), the specified parts of the hymn will be augmented with a chorus per verse if no chorus is included.
7 Auto Add Chorus ON 5:14 𝄞 HFW-Revised #5Verse 1, Chorus, Verse 4, Chorus
8 Auto Add Chorus OFF 5:14 𝄞 HFW-Revised #5Verse 1, Verse 4

Blank/Text-only Slides (Internal Viewer ONLY)

To add a blank slide, enter W (for white) or B (for black).  Optional text can be specified after a colon but the text may not include a semicolon since that indicates the next section of the entry.
